# 조사 자동 선택 패치 (v12부터)

「%s」에 들어가는 이름의 받침에 따라 을/를, 이/가, 은/는, 과/와, (으)로, (이)야·(이)라면, (이)에요를 게임이 실행 중에 고른다.
도구는 `tools/particle_patch.py`이고, `build_korean_test_rom.py`가 빌드할 때 자동으로 넣는다.

## 번역 파일 쓰는 법

`translations/ko.json`에는 지금처럼 `을(를)`, `이(가)`, `은(는)`, `과(와)`, `(으)로`, `(이)…`, `(이)에요`로 쓴다.
빌드 때 이 표기가 표시 문자로 바뀐다. 「%s」 뒤가 아닌 곳에 써도 바로 앞 글자 기준으로 동작한다.

## 동작

- 메시지 문장 함수 `0x020D9F4C(mode, buf, fmt, va)`를 부르는 6곳의 BL을 ITCM 끝 `0x01FFFDC0`의 래퍼로 돌렸다.
  - 호출 위치: `0x020767B2`, `0x02076826`, `0x02076862`, `0x020ADB9E`, `0x020D9F2A`, `0x020D9F46`
  - 래퍼는 원래 함수를 그대로 부른 뒤, 버퍼의 표시 문자를 조사로 바꾼다. 쓰지 않는 표시는 지운다.
- 코드는 ARM9에 새 autoload 블록(ITCM `0x01FFFDC0`, 336바이트)으로 들어간다.
  - ITCM 끝 576바이트는 세이브 스테이트 6개에서 모두 0이었다.
  - ARM9 파일은 348바이트 늘어난다. 바로 뒤의 Nitro 꼬리표 12바이트도 같이 옮긴다. ARM7 앞 여유 424바이트 안에 들어간다.
- 받침 판별
  - 한글 글자 번호를 「받침 없음 → ㄹ 받침 → 그 밖의 받침」 순서로 매겨, 번호 범위로 판별한다.
  - 숫자는 읽기(영·일·이·삼…)로 판별한다. 문장 함수가 숫자를 글꼴 숫자 `0x8740`('1')~`0x8749`('0')로 바꾸므로 그 코드도 함께 본다.
  - 「」」, 「』」, 「）」, 공백, 태그(0x1A)는 건너뛰고 그 앞 글자를 본다.
  - (으)로는 ㄹ 받침을 「받침 없음」으로 친다.

## 검증 (2026-11-06)

- PC 에뮬레이터(유니콘)로 확인했다. 세이브 스테이트 4번의 실제 RAM·ITCM에 v12 코드를 넣고 실제 문장 함수로 돌렸다.
