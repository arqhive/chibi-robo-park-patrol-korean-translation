■ 준비물
- 일본판 롬(제품 코드 AJBJ). 북미판·유럽판에는 적용할 수 없습니다.
- BPS 패치 도구.
  Rom Patcher JS: https://www.marcrobledo.com/RomPatcher.js/
  또는 Floating IPS(Windows).

■ 적용 방법 (Rom Patcher JS)
1. 위 주소를 엽니다.
2. ROM file에 원본 일본판 롬을 넣습니다.
3. Patch file에 AJBJ_KPatch_v1.0f.bps를 넣습니다.
4. Apply patch를 누르면 한글판 롬을 내려받습니다.

■ 적용 방법 (Floating IPS)
1. flips.exe를 실행하고 Apply Patch를 누릅니다.
2. AJBJ_KPatch_v1.0f.bps를 고릅니다.
3. 원본 일본판 롬을 고릅니다.
4. 저장할 파일 이름을 정합니다.
